DO NOT MODIFY FILES HERE

Every .html file in this folder is GENERATED by scripts/build.js.
Any edit you make here is overwritten the next time the site is built.

Edit the sources instead:
  sources/   page content (one file per page)
  elements/  header, menu, widgets, footer, and the page layout

Then rebuild:  node scripts/build.js

(This file is not served by the web server. See README.md in this folder.)
